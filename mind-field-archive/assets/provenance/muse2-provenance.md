# MIND FIELD design assets — Batch 2, MUSE share: provenance

- Date: 2026-11-04
- Tool/model: Muse media pipeline, `media.generate_image` (image generation subagent). Candidates were generated into `~/workspace/mindfield-assets/gen/`, self-checked visually, and the selected candidate for each target was re-encoded to JPEG sRGB quality 82 (Pillow, optimize) and saved under the final name in `archive/assets/`. No other post-processing (no cropping, no color edits).
- Resolution note (honest shortfall, same as batch 1): the generator capped output below the requested pixel sizes on every image. The largest output was kept in each case; requested vs actual sizes are listed per image.
- Size caps: floor-texture image (M-1) ≤900KB, all others ≤700KB — all finals comply at q82.
