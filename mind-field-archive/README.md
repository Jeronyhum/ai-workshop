# MIND FIELD: 바이브코딩 워크숍 아카이브

바이브코딩 워크숍 자료를 관람 순서 없는 전시장처럼 걷는 사이트입니다. 넓은 바닥 위에 1부(AI가 바꾸는 일과 산업), 다리, 2부(에이전트 엔지니어링의 개념)가 놓여 있고, 출구에서는 기초 용어와 OpenCode 설치 안내를 보며 "오늘 뭘 만들지" 정합니다. 전문 용어에 마우스를 올리면 쉬운 한국어 설명이 뜹니다.

데스크톱 브라우저용입니다.

## 여는 법

- `index.html`을 브라우저로 바로 열면 됩니다. 빌드 단계가 없습니다.
- 로컬 서버로 열어도 됩니다: 이 폴더에서 `python3 -m http.server 8000` 후 <http://localhost:8000/>.
- 특정 조각은 주소 끝에 `#조각id`를 붙여 바로 엽니다(예: `index.html#accounting`).

## 도슨트 키

| 키 | 하는 일 |
|---|---|
| `←` `→` `↑` `↓` | 그 방향에서 가장 가까운 조각으로 |
| `Tab` | 실로 이어진 다음 이웃으로 걷기. 방금 지나온 조각은 건너뜁니다. 안내판에 다음 이웃이 보입니다 |
| `Shift` `Tab` | 걸어온 길을 한 걸음 되돌아가기 |
| `Enter` | 조각을 방으로 열기 |
| 방 안에서 `←` `→` | 이웃 방으로 걷기, 되돌아가기 |
| `Esc` | 한 단계 물러나기: 방 → 조각 → 구역 → 전체 → 위쪽 도구 |
| `D` | 도슨트 조명: 지금 조각과 이웃, 그 실만 밝게. 실의 이유가 실 위에 뜨고, 안내판이 이웃 목록을 펼치며, 방 글자가 1.2배 커집니다. 2부 도식은 1단계에서 기다리고 안내판에 단계가 나옵니다 |
| `.` `,` | 2부 도식을 한 단계 앞, 뒤로. 바닥과 방 모두 |
| `0` `1` `3` `2` | 전체, 1부, 다리, 2부 |
| `+` `−` | 확대, 축소. 끌어서 걷고, Ctrl과 휠로 확대합니다 |
| `L` | 목록으로 보기 |
| `M` | 모션 기본과 줄임 전환. 처음 값은 운영체제 설정을 따릅니다 |
| `?` | 키 지도 |

- 글자 키는 `KeyboardEvent.code`를 쓰고 IME 조합 중인 입력은 무시합니다. 한글 입력 상태에서도 작동합니다.

## 확인 도구

`tools/check.py`는 링크, 글꼴, 공개 문구 규칙을 검사합니다. 원자료가 없는 체크아웃에서는 그 부분을 NOT_RUN으로 표시하고 통과합니다. 브라우저 테스트(`tools/test_*.py`)는 Playwright가 필요합니다.

## 크레디트와 라이선스

글꼴, 디자인 시스템, 이미지와 외부 자료의 출처는 [`CREDITS.md`](CREDITS.md)와 [`CREDITS-libs.md`](CREDITS-libs.md)에 있습니다. 갤러리의 각 사례는 원 게시물로 링크됩니다.
